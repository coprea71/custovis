What is Custovis?

Custovis is an open-source (AGPL-3.0) service suite built on Laravel 12 that combines shared-mailbox ticketing, ITIL processes with a CMDB, a knowledge base, a customer portal, AI assistance and technician dispatching in one self-hosted application. It is aimed at customer service teams, IT departments and service providers, and companies with field technicians who want one self-hosted system instead of several paid tools.

Features

Everything below is part of the free release. There are no editions, no paid modules and no limits on agents, tickets or mailboxes.

Shared-mailbox ticketing

Any number of IMAP mailboxes become tickets; replies go out via each team's SMTP. Canned responses, tags, internal notes, spam filter, collision detection.

ITIL processes

Incident, problem, change with CAB approval and service requests from a catalogue. SLA engine with business hours and customer-specific SLAs.

CMDB

Configuration items and their relations, linked to incidents and changes.

AI assist with your own keys

Summaries, reply suggestions, triage and similar tickets via OpenAI, Anthropic, Ollama or a custom endpoint. Budgets per team, optional PII redaction.

Field service

Technician skills, shifts and absences, dispatcher board with map and assignment suggestions, offline PWA with checklists, signature and delivery note PDF.

Channels

Email, WhatsApp Business, REST API, GitHub/GitLab issue import and an MCP interface for AI phone assistants.

Knowledge base & portal

Versioned Markdown articles, public help centre, customer portal with ticket history and service catalogue requests.

Time tracking & e-invoicing

Timer on tickets, single and collective invoices as ZUGFeRD PDF and XRechnung XML with GoBD-compliant numbering.

Compliance

Mandatory 2FA, passkeys, audit log, encrypted credentials, GDPR export and anonymisation, retention periods.

Installation in three steps

  1. Download the release archive from GitHub. It already contains all dependencies and built assets.
  2. Upload it via FTP/SFTP and point your domain to the public/ folder.
  3. Open /install in your browser, enter the database credentials and create the first administrator.

Frequently asked questions

What is Custovis?

Custovis is an open-source (AGPL-3.0) service suite built on Laravel 12 that combines shared-mailbox ticketing, ITIL processes with a CMDB, a knowledge base, a customer portal, AI assistance and technician dispatching in one self-hosted application.

Is Custovis really free?

Yes. All features are included under the AGPL-3.0 license. There are no paid editions, no paid modules and no limits on agents, tickets or mailboxes. AI features use API keys you configure yourself, so you only pay your AI provider.

Does Custovis run on shared hosting without SSH?

Yes. The release archive contains all dependencies and built assets. You upload it via FTP/SFTP, run the web installer, and later install updates and database migrations with one click in the admin area. A web cron URL replaces the cron job and queue worker.

Which languages does Custovis support?

The user interface is currently available in German only. The README and this website are available in English and German.

Do I need a WebSocket server for real-time features?

No. With Laravel Reverb configured, team chat and collision detection update instantly. Without it, both fall back to polling, so everything works on plain PHP hosting.

How does Custovis compare to FreeScout, Zammad and GLPI?

Custovis covers helpdesk, ITIL service management and field service in a single application without paid add-ons. FreeScout focuses on shared inboxes with paid modules, Zammad on omnichannel customer support, and GLPI on IT asset and service management. See the comparison pages for details.
