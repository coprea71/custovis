Das Theme bestimmt das Erscheinungsbild von Custovis. Es gilt für die gesamte Installation: Agenten-Bereich, Administration und Kundenportal.

## Theme wechseln

1. Öffnen Sie **Administration → Theme**.
2. Sehen Sie sich die Vorschaubilder der verfügbaren Themes an. Das aktuelle Theme ist mit **Aktiv** markiert, das mitgelieferte mit **Standard**.
3. Klicken Sie beim gewünschten Theme auf **Aktivieren**.
4. Laden Sie die Seite neu und prüfen Sie Agenten-Bereich und Kundenportal.

## Eigenes Theme hinzufügen

1. Legen Sie per FTP/SFTP einen neuen Ordner mit einer Datei `theme.json` im Theme-Verzeichnis der Installation an. Der genaue Pfad steht auf der Seite **Theme**.
2. Rufen Sie **Administration → Theme** auf. Das neue Theme erscheint automatisch in der Liste.
3. Aktivieren Sie es wie oben beschrieben.

## Gut zu wissen

- Erscheint ein Theme nicht, ist seine `theme.json` wahrscheinlich ungültig.
- Sie können jederzeit zum **Standard**-Theme zurückwechseln.
