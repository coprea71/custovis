# Plan 12: Veröffentlichung

Gemeinsame Grundlage: [0.md](0.md). Voraussetzung: alle vorherigen Pläne.

## Ziel dieser Session

Web-Installer final, CI, Demo-Daten, erstes Release.

## Aufgaben

- Web-Installer (`/install`, siehe [0.md](0.md) Repo-Struktur) final
  ausbauen: DB-Test, Migrationen, Admin-Anlage, Abschluss-Sperre
  (`storage/installed.lock`).
- Schema-Update-Route `/admin/system/migrate` (Permission
  `system.maintain`) für spätere Versionen ohne Shell-Zugriff.
- GitHub-Actions-CI: Tests (`php artisan test`), Lint/Static Analysis.
- Demo-Seeder für ein realistisches Vorführ-Setup (Teams, Tickets aller
  Typen, KB-Artikel, Chat-Nachrichten).
- Finaler README-/CHANGELOG-Check vor Release-Tag.
- Erstes GitHub-Release (Tag, Release Notes aus CHANGELOG).

## Verifikation

- Frischer Web-Installer-Durchlauf auf einer leeren DB (nur SFTP/FTP-
  Upload, kein Shell-Zugriff simuliert) führt zu einer funktionsfähigen
  Instanz.
- CI-Pipeline läuft grün auf einem frischen Branch.
- Demo-Seeder erzeugt ein konsistentes, vorführbares Test-System.
