# Plan 18: Startseite, Navigation & Konto-Menü

Gemeinsame Grundlage: [0.md](0.md). Voraussetzung: [17](archiv/17.md) (Basis-Layout).

## Ausgangslage

`/` zeigt noch die Laravel-Standardseite. In keinem Bereich gibt es einen Logout, der
Agenten-Bereich verlinkt weder `/admin` noch die Kontosicherheit, der Admin-Bereich hat
keinen Rückweg.

## Ziel

- **Startseite `/`**: eigene, SEO-/GEO-taugliche Einstiegsseite (Titel, Meta-Description,
  Schema.org `SoftwareApplication`, semantisches HTML, zitierfähige Kurzbeschreibung)
  mit Links zu Agenten-Login, Kundenportal und ggf. Techniker-App; angemeldete Nutzer
  werden direkt in ihren Bereich weitergeleitet.
- **Konto-Menü** in Agenten- und Admin-Layout: Name, Link „Kontosicherheit (2FA)",
  Wechsel Agent ↔ Administration (nur mit passenden Rechten), **Abmelden** (POST, CSRF).
- Admin-Navigation zeigt nur Einträge, für die der Nutzer Rechte hat.
- Portal hat bereits Logout (Plan 10) — nur prüfen.

## Verifikation

- `/` liefert 200 mit Meta-Description und JSON-LD; eingeloggter Agent wird nach `/agent` geleitet.
- Logout aus Agent und Admin beendet die Sitzung.
- Nutzer ohne Admin-Rechte sehen keinen Admin-Link.
