# Plan 26: WhatsApp-Webhook-URL in den Team-Einstellungen anzeigen

Gemeinsame Grundlage: [0.md](0.md).

## Ausgangslage

Die Callback-URL für Meta lautet `/webhooks/whatsapp/{account}`. Die
Konto-ID wird in `WhatsappAccountManager` nirgends angezeigt; das Hilfethema
`whatsapp` verweist deshalb auf „Die Konto-Nummer erhalten Sie bei Ihrer
Administration“. Bei Git-Issues wird die Webhook-URL dagegen direkt angezeigt.

## Ziel

- Je WhatsApp-Konto die vollständige Callback-URL anzeigen (kopierbar), analog
  zu `GitIssueConnectionManager`.
- Hilfethema `whatsapp` anpassen: „Kopieren Sie die angezeigte Callback-URL“.
